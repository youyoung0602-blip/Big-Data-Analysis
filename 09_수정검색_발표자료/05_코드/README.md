# 재현 방법

Python 3.11.2와 scikit-learn 1.8.0에서 실행했다. pandas, numpy, scipy, matplotlib이 필요하다. 그래프의 한글 글꼴은 맑은 고딕을 사용한다.

저장소 루트에서 실행한다. `--source`에 사용자가 제공한 원본 CSV 경로를 입력한다. `--local`은 패밀리 대표 문헌과 희소행렬을 저장할 로컬 폴더다.

```powershell
python "09_수정검색_발표자료/05_코드/build_v2_review.py" --source "<원본 CSV 경로>" --repo "." --local "../v2_review_local"
```

집계표는 `03_집계표`, PNG는 `04_그래프`에 생성된다. 원문 포함 대표 문헌, TF-IDF 희소행렬, 어휘 배열은 지정한 로컬 폴더에 생성된다. 전처리의 불용어·복수형 목록은 저장소 내 `08_검색식개선_단계별/02_용어정제_TFIDF`의 공개 목록을 읽는다. 이 파일들도 같은 커밋으로 체크아웃해야 기준을 재현할 수 있다.

코드는 원본을 덮어쓰지 않으며 공개연도 조건을 계산에 적용한다. 패밀리는 구성원 ID 교집합의 연결 성분으로 계산한다. CSV 자체의 전체 검색식과 다운로드 완전성은 코드로 검증할 수 없어 별도 확인이 필요하다.
