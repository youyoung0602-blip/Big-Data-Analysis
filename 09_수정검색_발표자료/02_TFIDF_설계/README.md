# TF-IDF 분석 설계

## 확정한 입력과 설정

| 항목 | 적용 기준 |
|---|---|
| 분석 범위 | 미국 공개문헌, 공개연도 2015~2024 |
| 분석 단위 | 관측된 simple family 연결 그룹당 대표 문헌 1개, 총 4,594개 |
| 입력 필드 | Title과 Abstract, 동일 가중치 |
| 대표 문헌 선택 | 범위 내 공개일이 가장 이른 문헌, 동률은 Lens ID 순서 |
| 정규화 | 소문자, 약어·구문 표기 통합, 제한된 복수형 사전 |
| 불용어 | 기존 08의 영어·특허 상투어 목록, 부정·관계어 일부 보존 |
| 특성 | 단어와 정제 후 인접 2단어 구문, 제목·초록 경계 연결 차단 |
| 문헌 빈도 하한 | min_df=5 |
| 문헌 빈도 상한 | max_df=1.0 |
| TF | 등장 횟수 f>0에 대해 1+ln(f) |
| IDF | ln((1+N)/(1+df))+1 |
| 문헌 벡터 | L2 정규화 |
| 어휘 학습 | 전체 4,594개에서 1회 적합 |
| 기간 비교 | 같은 어휘·IDF를 유지하고 기간별 집계 |

제목을 임의로 반복해 가중치를 높이는 방식은 이번 기준에서 사용하지 않았다. 필드 가중치는 동일하게 두고, 후속 필요 시 제목 가중치 2와의 결과 차이를 검토한다. 청구항 전문은 현재 CSV 입력 필드에 포함되지 않아 사용하지 않았다.

`UE/user equipment`, `CSI/channel state information`, `DRX/discontinuous reception`, `NR/new radio`, `WiFi/Wi-Fi`, `side-link/sidelink` 등을 통합한다. `resource pool`, `random access`는 합성 토큰으로 보존한다. 원형 통합은 공개된 사전 범위에만 적용한다. `5g`, `4g`, `pc5`, `pdcch` 등 문자·숫자 혼합 용어는 유지하며 순수 숫자 토큰은 제외한다. 실행 코드에 정확한 패턴이 포함돼 있다.

2단어 구문은 불용어 제거 이후 인접한 토큰으로 생성한다. 정제 과정에서 원문에서 떨어져 있던 단어가 인접할 수 있으므로 이를 원문 그대로의 고정 표현으로 해석하려면 초록을 확인한다.

## min_df=5를 선택한 근거

| min_df | 특성 수 | 빈 문헌 | min_df=5와 상위 20개 용어 집합 일치율 |
|---|---|---|---|
| 3 | 14,248 | 0 | 100% |
| 5 | 7,730 | 0 | 100% |
| 10 | 3,830 | 0 | 100% |

min_df=5는 약 0.109%인 5개 문헌 이상에 등장하는 특성을 남긴다. 하한 3에서 특성이 크게 증가해도 상위어 집합은 같았고, 하한 10에서는 드문 세부 용어가 더 많이 제외된다. 이 비교를 근거로 5를 기준값으로 채택했다. 상위어 집합 일치율은 토픽 정확도와는 별도로 평가해야 한다. [민감도 원자료](../03_집계표/tfidf_sensitivity.json)

`max_df=1.0`으로 공통 기술 용어를 보존한다. `wireless`, `communication`, `user_equipment`의 제거 여부는 기술 구분력과 대표 문헌 검토를 거쳐 판단한다. 희귀 용어는 주모델의 빈도 하한에서 빠져도 원문 검토 대상에 포함할 수 있다.

## 이번 실행 결과

입력 4,594개, 특성 7,730개, 빈 문헌 0개다. 행 벡터의 L2 노름, 유한값, 비음수값을 검사했다. 기술 내용에 따른 문헌 제외 수는 0개다. 공개연도 범위 밖 1,840개는 기간 설정에 따라 별도 집계했다.

평균 TF-IDF 상위에는 `user_equipment`, `sidelink`, `communication`, `transmission`, `wireless`, `resource`, `channel`, `base_station`, `channel_state_information` 등이 포함된다. [전체 용어별 점수와 문헌 빈도](../03_집계표/tfidf_keywords.csv)

L2 정규화된 문헌 벡터의 점수 합은 고유 용어 수의 영향을 받는다. 따라서 점수 합이나 평균 하나로 문헌의 중요도 순위를 정하면 내용 관련성이 제대로 반영되지 않을 수 있다. 문헌 제외 기준은 검토 표본의 관련성 판정과 오탐·누락 평가 후 결정한다.

## NMF 후속 분석 기준

1. 위 TF-IDF 행렬로 NMF 토픽 수 6·8·10·12를 비교한다.
2. 각 후보는 seed 7·42·99로 반복하고 토픽 벡터 코사인 유사도를 최대 매칭해 안정성을 측정한다.
3. 토픽별 상위 15개 용어, 상위 기여 문헌 5개와 무작위 문헌 5개의 내용을 확인한다. 의미가 다른 기술의 혼합, 같은 기술의 과도한 분할, 상투어 중심 토픽을 기록한다.
4. 재구성 오차, 초기값 안정성, 사람이 해석한 토픽 간 구분을 함께 보고 토픽 수를 결정한다. 기존 표본의 8개라는 값은 후보 중 하나로 검토한다.
5. 확정한 모델과 토픽명을 모든 연도에 고정해 적용한다. 기간별 패밀리 수와 비중을 함께 제시한다.
6. 토픽별 최대 상대 가중치가 0.35 미만이거나 상위 두 가중치 차이가 0.10 미만이면 혼합 후보로 표시하고 문헌을 확인한다. 이 임계값은 검토용 잠정값이며 초기 수동 검토 후 조정한다.

NMF 토픽별 상대 가중치는 행의 성분을 합으로 나눈 요약값이다. 확률적 분류의 정답 확률로 해석하려면 별도의 검증이 필요하다. 이번 작업은 TF-IDF 설정과 예비 계산까지 완료했으며 새 NMF는 아직 실행하지 않았다.

## 사이드링크 연구 범위 검증

전체 4,594개 중 사이드링크·PC5 언급은 1,287개, 여기에 자원·스케줄링·grant·preemption·DRX·중계 조건이 함께 있는 문헌은 804개다. 이 조건의 정확한 정규식은 코드에 기록했다. 두 수치는 NMF 토픽 개수와 별도로 관리한다.

사이드링크 중심 후보 검색을 의도했다면 실제 Lens 검색 이력에서 필수 조건과 괄호 구조를 확인한다. CSV의 제목·초록은 검색 시점의 인덱스 내용·패밀리 검색 설정과 차이가 있을 수 있어, 문자열 매칭의 불일치 원인은 검색 이력과 문헌을 대조해 판단한다.

804개 일치·나머지 문헌에서 각각 50개씩 고정 난수로 뽑아 관련 여부를 검토하고, 실제 관련 문헌 누락과 비관련 문헌 유입을 기록하는 절차를 권한다. 이 표본 검토는 후속 실행 항목이다. 양성 판정 기준은 사이드링크 자원 할당, 사이드링크 DRX, 단말 중계 중 하나가 제목·초록에서 중심 기술로 설명되는 경우로 두고, 애매한 문헌은 별도 표기한다.

## PCA를 사용할 경우

PPT 기술 지도를 위해 추가 수행할 경우 중심화 PCA의 10개 주성분을 계산하고 PC1·PC2와 PC1~PC10의 설명분산비를 함께 제시한다. 고차원 원문 공간의 이웃 보존율도 점검한다. 희소행렬에 TruncatedSVD를 적용하면 비중심화 분해라는 계산 정의를 표시한다. 이번 실행에서 PCA 좌표와 설명분산은 아직 계산하지 않았다.
