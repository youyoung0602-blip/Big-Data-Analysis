**결과를 읽을 때는 [06_결과해석_검증](./06_결과해석_검증/)을 먼저 참고하세요.** 분야별 특징을 직접 비교하고 PCA 지도 해석의 한계를 수치로 점검했다. min_df 3·5·8에서 주요 10차원 부분공간의 중첩도는 기준 대비 94.7~98.2%다. 반면 PC10의 원래 최근접 이웃 보존율은 27.2%이므로 산점도 거리만으로 기술 유사성을 확정하지 않는다.

최신 PCA 분석은 **05_PC10_용어정제**에 있다. 상위 10개 CPC에 해당하는 606개 문헌을 대상으로 정제 전후를 비교했다. PC1~PC10 누적 설명분산은 **10.49% → 12.71%**다. 기존 PC1·PC2 보고서는 이전 분석 결과로 보존했다.

분석 대상은 원본 특허 문헌 1,000건에서 중복·언어 처리를 거친 658개 패밀리 대표 문헌입니다. 결과는 제공된 표본에 대한 분석이며 퀄컴 전체 포트폴리오의 비중이나 전략 변화를 확정하지 않습니다.
