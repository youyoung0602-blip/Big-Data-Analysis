# 검색식 개선 — 단계별 작업

후속 자료는 [09_수정검색_발표자료](../09_수정검색_발표자료/)에 있다. 수정 검색 이후 제공된 v2 CSV를 공개연도 2015~2024 기준 4,594개 관측 패밀리로 정리했다. 아래 단계별 상태와 수치는 기존 495개 표본 작업의 기록이다. 새 CSV만으로 원검색식 전체의 패밀리 수와 다운로드 완전성을 확정하기는 어려워 Lens 검색 이력 검증 항목을 남겼다.

목표: 수정 검색식으로 Lens의 Simple Families 검색 결과를 5,000개 이하로 좁힌다. 전체에서 대표 문헌 5,000개를 뽑는 표본 선정과 구분한다.

| 단계 | 목적 | 상태 |
|---|---|---|
| [01 데이터 점검](./01_데이터점검/) | qualcom1.csv 범위 확인·패밀리 중복 정리 | 완료 |
| [02 용어 정제·TF-IDF](./02_용어정제_TFIDF/) | 불용어·표기 통합과 기술 용어 표현 및 결과 검증 | 완료 |
| [03 토픽모델링](./03_토픽모델링/) | NMF 토픽 수·초기값 비교, 대표 용어와 문헌 검토 | 완료 |
| [04 포함·제외 주제 검토](./04_연구범위검토/) | 사이드링크 자원 할당·DRX·중계로 범위 선택, 후보별 표본 비교 | 완료 |
| 05 검색식 후보 작성 | 핵심어·세부 CPC와 조건 조합 | 다음 단계 |
| 06 Lens 실행 검증 | 패밀리 수와 관련 문헌 누락 확인 | 예정 |

각 단계의 결과를 확인한 뒤 다음 단계로 이어간다. 지금까지 노이즈 문서를 확정해 삭제하거나 5,000개 이하로 줄였다는 의미는 아니다. 현재 파일은 전체 검색 결과 중 1,000개 문헌만 포함하므로 검색식 후보의 전체 결과 수는 Lens에서 확인해야 한다.
